# Weekly video prompts

One folder per week (`prompts/YYYY-MM-DD/`), one `.md` file per video. Each file starts
with 3 title options and thumbnail text (2–5 words, different from the title), then the
Project Crafter prompt in the same section order as the app's Crafter prompt tab:
TITLE, NARRATOR, AUDIENCE, LENGTH, OUTPUT FORMAT, STRUCTURE (numbered list),
SAFETY/ACCURACY, PRODUCT MENTIONS, STYLE RULES. There is no SOURCES section, and the
prompt always ends with the exact line `create me a prompt for the video`.

Copy everything below the `---` line into Project Crafter. Product links carry
`?utm_source=youtube&utm_medium=video&utm_campaign=<video>`.
